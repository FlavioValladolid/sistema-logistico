# Canal B2B/B2C con Clientes Retail — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add configurable B2B/B2C channel to client profiles; B2B clients require selecting a retailer at tracking start, which persists in the tracking record and appears in the tracking table, CSV reports, and manifests.

**Architecture:** Two new TEXT columns on `clientes` (`tipo_canal`, `clientes_retail` as JSON array) and one TEXT column on `trackings` (`retailer`). Backend: migrate, propagate through existing CRUD + CSV endpoints. Frontend: clientes modal + table badge, operacion start form, trackings table column, reportes CSV + manifest header. Five tasks in dependency order — backend first, then each frontend view.

**Tech Stack:** Node.js + Express, better-sqlite3, vanilla JS, HTML — no new dependencies

## Global Constraints

- SQLite migrations: `ALTER TABLE … ADD COLUMN` with try/catch (same pattern as `requiere_fotos_sku_nuevo` at server.js:421)
- No new npm packages
- Pure vanilla JS — no TypeScript, no build step
- `clientes_retail` stored as JSON string in TEXT column; parsed with `JSON.parse(col || '[]')`
- NULL `tipo_canal` means "not configured" — existing clients and trackings are unaffected
- The retailer dropdown only appears in operacion.html when `tipo_canal === 'B2B'`
- Retailer is required at tracking start only when `tipo_canal === 'B2B'`
- B2C clients and unconfigured clients skip the retailer field entirely

```js
function onCanalChange(canal) {
  const esB2B = canal === 'B2B';
  const esB2C = canal === 'B2C';
  document.getElementById('btn-canal-b2c').style.cssText =
    `display:flex;align-items:center;gap:10px;padding:12px 14px;border-radius:var(--radius-sm);cursor:pointer;border:${esB2C ? '2px solid var(--accent-green);background:rgba(0,230,118,0.08)' : '1px solid var(--border);background:var(--bg-elevated)'}`;
  document.getElementById('btn-canal-b2b').style.cssText =
    `display:flex;align-items:center;gap:10px;padding:12px 14px;border-radius:var(--radius-sm);cursor:pointer;border:${esB2B ? '2px solid var(--accent-green);background:rgba(0,230,118,0.08)' : '1px solid var(--border);background:var(--bg-elevated)'}`;
  document.getElementById('seccion-retail').classList.toggle('hidden', !esB2B);
}

function agregarRetailer() {
  const input = document.getElementById('retail-input');
  const nombre = input.value.trim();
  if (!nombre) return;
  const lista = document.getElementById('retail-lista');
  const existing = [...lista.querySelectorAll('[data-retailer]')].map(el => el.dataset.retailer.toLowerCase());
  if (existing.includes(nombre.toLowerCase())) { input.value = ''; return; }
  const chip = document.createElement('span');
  chip.dataset.retailer = nombre;
  chip.style.cssText = 'display:inline-flex;align-items:center;gap:4px;background:var(--bg-surface);border:1px solid var(--border);border-radius:12px;padding:3px 10px;font-size:12px';
  chip.innerHTML = `${escHTML(nombre)} <button type="button" onclick="this.parentElement.remove()" style="background:none;border:none;cursor:pointer;color:var(--text-muted);font-size:14px;line-height:1;padding:0;margin-left:2px">✕</button>`;
  lista.appendChild(chip);
  input.value = '';
  input.focus();
}
```

# Canal B2B/B2C — Corrección de Diseño (v2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corregir el diseño del canal B2B/B2C: en clientes.html el canal se ACTIVA con un toggle (no se selecciona B2B/B2C ahí); la selección de B2B o B2C ocurre al iniciar cada tracking en operacion.html.

**Architecture:**
- `clientes.tipo_canal`: `'B2B'` = B2B habilitado para ese cliente, `NULL` = no habilitado. Sin valor 'B2C' a nivel cliente.
- `trackings.canal`: `'B2B'` o `'B2C'` elegido por el operador al iniciar cada tracking (cuando el cliente tiene B2B habilitado). `NULL` para clientes sin B2B habilitado.
- `trackings.retailer`: nombre del retailer seleccionado (solo cuando `canal = 'B2B'`).

**Tech Stack:** Node.js + Express, better-sqlite3, vanilla JS + HTML. Sin nuevas dependencias.

## Global Constraints

- Sin nuevos paquetes npm
- Vanilla JS puro — sin TypeScript
- Migraciones: `ALTER TABLE … ADD COLUMN` con try/catch
- `clientes.tipo_canal`: solo almacena `'B2B'` o `NULL` — nunca `'B2C'`
- `trackings.canal`: `'B2B'` o `'B2C'` (elegido al iniciar) o `NULL` (cliente sin B2B)
- `escHTML()` disponible globalmente desde `app.js`
- YAGNI: no agregar funcionalidad fuera del alcance de esta corrección
